# Changelog

## 4.0.0

- Added a full ten-day, multi-timescale context feature engine.
- Added 2-, 3-, 5-, 7- and 10-day price, volume, volatility, trend and market-relative features.
- Added breakout/failed-breakout, shock-frequency and same-time activity features.
- Added explicit exploratory-reuse and fresh-staged research modes.
- Added fixed historical scan start/end dates with a maximum 180-day span.
- Added separate ten-day context index, exploratory, discovery, validation and sealed-test packages.
- Added `binance_context_jobs`, `binance_context_files` and `binance_context_issues` tables.
- Added restart recovery and dashboard progress for context jobs.
- Preserved all v3 scanner, event archive and matched-control functionality.

## 3.0.0

- Added matched same-coin non-surge controls and staged packages.
